# Elsewhere

Els is a responsive travel-wishlist app built with Next.js. Collect
destinations for later, browse by region, search your list, and save the places
you want to remember.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the app.

## Features

- Browse destination ideas across Europe, Asia, Africa, and the Americas.
- Search destinations by name, country, or travel notes.
- Save and unsave destinations or filter the list to saved places.
- Pick a surprise destination for inspiration.

Saved places are kept in the current page session and are not synced to an
account or stored on a server.

## Production

```bash
npm run build
npm start
```
